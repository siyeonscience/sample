# 과학으로 여는 자물쇠

학생용 과학 방탈출 웹앱 예시입니다. 별도 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 진행 흐름
1. 타이틀 화면 → **입장 →**
2. 닉네임 입력 + 개인정보 수집·이용 동의 → **시작하기** (둘 다 해야 버튼 활성화)
3. 스토리 안내 (타이핑 효과, SKIP 가능) → **네 알겠습니다**
4. 과학 구조대 신분증 등장 연출 → 신분증이 왼쪽 위로 이동하고, 색색의 클립이 든 투명 아크릴 큐브 등장 (드래그로 회전)
5. 신분증을 끌어서 상자에 가져다 대면(또는 신분증 클릭) 색이 서로 다른 진짜 클립 7개만 자석에 끌려 나와 신분증에 매달림 (나머지는 가짜)
6. 오른쪽 아래 잠긴 상자 클릭 → 칸마다 색이 다른 7칸 자물쇠. 같은 색 클립의 알파벳을 넣으면 **SCIENCE** 완성 → 상자가 열리고 빨간 셀로판지 획득

## 정답표 (교사용)
| 자물쇠 칸 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 색 | 파랑 | 노랑 | 빨강 | 보라 | 초록 | 분홍 | 주황 |
| 알파벳 | S | C | I | E | N | C | E |

색·알파벳 짝은 `index.html`의 `SPECIAL` 배열에서, 신분증에 매달리는 순서는 `HANG_ORDER`에서 바꿀 수 있습니다.

닉네임은 브라우저 메모리에만 있고 어디에도 저장·전송되지 않습니다.
